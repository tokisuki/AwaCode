# 两分钟演示与最终提交指南

本项目提供可重复演示夹具，但不生成或伪造视频。录制者仍需自己完成 MP4（**不超过 2 分钟、200 MB**，且画面不得出现 API Key）并提交。

## 演示前复位

使用 Node 24，从仓库根目录执行：

```powershell
node demo\reset.mjs --target demo\.workspace\recording
```

`--target` 是必填项，且脚本只接受 `demo/` 内部的目标。脚本删除该明确目标后，从只读 `demo/fixture/` 复制一个带折扣边界 bug 的小型 Node 测试项目；它不会触碰项目外路径、真实用户数据或任何模型配置。固定提示词：

> 修复购物车折扣边界问题，使全部测试通过，不要修改测试文件；完成后说明改动和测试结果。

在桌面端选择 `demo\.workspace\recording`，使用录制者自己的、已在 Settings 中保存的配置。不要在屏幕、命令行、日志或旁白中展示 Key。

## 建议的 120 秒脚本

| 时间 | 录制内容 |
| --- | --- |
| 0–15 秒 | 展示 AwaCode、演示工作区和已配置状态；说明 Core 是本地 Node 24 进程。 |
| 15–75 秒 | 输入固定任务，展示计划、读取文件、失败测试、逐次批准命令和精确编辑。 |
| 75–95 秒 | 展示复测通过、模型直接给出的纯文本最终总结和工具时间线。 |
| 95–112 秒 | 展示重开会话历史，说明未完成副作用不会自动重放。 |
| 112–120 秒 | 简述 SQLite 持久化、上下文摘要、显式全局/项目记忆及“审批不是系统级沙箱”的限制。 |

可剪辑或加速，但不要把演示替换成静态截图；应包含一次真实的本地编程任务完成过程。
